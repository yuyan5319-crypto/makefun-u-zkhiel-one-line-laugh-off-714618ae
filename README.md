# makefun-u-zkhiel-one-line-laugh-off-714618ae

A single original funny line for make.fun's [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty. The program writes the line (85 characters, no trailing newline) to `/output/entry.txt` in the grading sandbox.

> "I asked my smart speaker for something to help me sleep. It read out my bank balance."

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs as-is). Set `MAKEFUN_OUTPUT_DIR` to choose the output directory; otherwise it writes to `/output`, falling back to `./output/entry.txt` when run by hand.
